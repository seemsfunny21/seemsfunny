# PEGASUS 310 — Προστασία αποθήκευσης και βίντεο ασκήσεων

Συνέχεια της 309, με **ίδιο πρόγραμμα, ίδιο UI και ίδια λειτουργία χρονομετρητών**.

- Το `Lat Pulldowns Close` χρησιμοποιεί το ξεχωριστό `videos/latpulldownsclose.mp4` όταν ο browser το αποκωδικοποιεί και το φορτώνει κανονικά. Αν υπάρξει σφάλμα video ή δεν φτάσει σε αναπαραγώγιμη κατάσταση μέσα σε 7 δευτερόλεπτα, γίνεται μία αυτόματη εναλλαγή στο δοκιμασμένο `videos/latpulldowns.mp4`. Η αλλαγή ισχύει για τη συγκεκριμένη συνεδρία και **δεν αλλάζει την ίδια την άσκηση ή τα σετ**.
- Το ίδιο fallback εφαρμόζεται και στην προεπισκόπηση επόμενης άσκησης. Τα δύο MP4 παραμένουν στα αρχεία και στην offline cache. **Δεν έγινε μετατροπή/επανεκκωδικοποίηση των MP4**: η κωδικοποίηση του ξεχωριστού βίντεο χρειάζεται επιβεβαίωση σε πραγματική συσκευή.
- Προστέθηκε κοινή ασφαλής ανάγνωση αποθηκευμένων JSON για desktop/κινητό, και προειδοποίηση μόνο όταν αποτυγχάνει πραγματική αποθήκευση. Τα errors και warnings δεν μπορούν πλέον να προκαλούν αλυσιδωτό σφάλμα όταν γεμίσει το `localStorage`.
- Αν αποτύχει η αποθήκευση ολοκλήρωσης προπόνησης εμφανίζεται μήνυμα αντί για ψευδή επιβεβαίωση επιτυχίας. Δεν διαγράφονται αυτόματα φθαρμένα αποθηκευμένα δεδομένα.
- Η πρόγνωση καιρού σταματά να περιμένει σε υποστηριζόμενους browser μετά από 7 δευτερόλεπτα, διατηρεί την προηγούμενη ένδειξη και δεν σταματά την προπόνηση.
- Η προαιρετική αποστολή EmailJS χειρίζεται αποτυχία τοπικής αποθήκευσης και ελλείπουσα βιβλιοθήκη, χωρίς να εμποδίζει την προπόνηση.
- Η offline cache αλλάζει σε v310, ενώ διατηρούνται παλιές αναγκαίες offline media caches.

**Backup κώδικα πριν τις αλλαγές:** `backup/pegasus-309-before-reliability-video-2026-11-07` (commit `4bee8b210473068defe746303c949b98484284fa`). Το backup του κώδικα **δεν** περιλαμβάνει προσωπικό ιστορικό browser· κράτησε και ξεχωριστό JSON export των δεδομένων σου.

Οι αυτοματοποιημένοι έλεγχοι είναι στο `tests/safety-regression.cjs` και εκτελούνται στο GitHub Actions. Η πλήρης επιβεβαίωση της αναπαραγωγής βίντεο απαιτεί δοκιμή σε πραγματικό browser.

# PEGASUS 309 — Συντήρηση ασφάλειας, χωρίς αλλαγή εμφάνισης

Η έκδοση 309 διατηρεί **το ίδιο εβδομαδιαίο πρόγραμμα, ασκήσεις, σετ, εμφάνιση και τους επιλεγμένους χρόνους**. Οι αλλαγές αφορούν μόνο αξιοπιστία:

- Πριν από επαναφορά στον υπολογιστή γίνεται έλεγχος αρχείου και επιχειρείται αυτόματη λήψη τοπικού αντιγράφου ασφαλείας. Η εισαγωγή δεν σβήνει τα υπόλοιπα δεδομένα του browser και επιχειρεί επαναφορά προηγούμενων τιμών σε αποτυχία.
- Τα δεδομένα φωτογραφιών από backup προστίθενται μόνο εάν δεν υπάρχει ήδη το ίδιο ID· δεν διαγράφεται η υπάρχουσα φωτοθήκη.
- Η παλιά (μη χρησιμοποιούμενη) ρουτίνα εισαγωγής κινητού παραπέμπει στην ήδη διαθέσιμη ασφαλή συγχώνευση.
- Ο μετρητής χρησιμοποιεί πραγματικά μεσολαβήσαντα δευτερόλεπτα και περιορίζει κάθε καθυστερημένο callback σε μία φάση· δεν μετρά επιπλέον ολοκληρωμένα σετ.
- Η ολοκλήρωση προπόνησης προστατεύεται από διπλή κλήση, ενώ οι καταγραφές σετ περιορίζονται στον πραγματικό αριθμό σετ της άσκησης.
- Η μόνιμη PWA cache δηλώνει επιτυχία μόνο όταν κατέβηκαν όλα τα ζητηθέντα αρχεία. Διατηρούνται παλιές offline media caches που περιέχουν αρχεία τα οποία λείπουν από τη νέα.
- Αν το Cache Storage αποτύχει, η εφαρμογή εξακολουθεί να μπορεί να φορτώσει από το δίκτυο.
- Το GitHub Actions τρέχει ανεξάρτητα τεστ `node tests/safety-regression.cjs` σε κάθε ενημέρωση του κύριου branch.

**Ασφαλές αντίγραφο κώδικα πριν από τις αλλαγές:** branch `backup/pegasus-308-before-hardening-2026-11-07`, commit `f927c854f2761a613f7fe004babca0c507351d38`.

**Σημαντικό:** ο κώδικας στο GitHub **δεν** περιλαμβάνει προσωπικό ιστορικό του browser. Για πραγματική προστασία των δεδομένων σου, κράτησε και εξωτερικό JSON backup με την επιλογή «Αποθήκευση αρχείου», σε ασφαλή φάκελο ή USB. Το αυτόματο αντίγραφο πριν από επαναφορά είναι επιπρόσθετη προστασία, όχι υποκατάστατο τακτικού backup.

# PEGASUS 308 — Προεπιλεγμένο διάλειμμα 90 δευτερολέπτων

Η έκδοση 308 αλλάζει την προεπιλογή του διαλείμματος από 60 σε 90 δευτερόλεπτα σε υπολογιστή και κινητό (10 δευτερόλεπτα προετοιμασία και 45 δευτερόλεπτα άσκηση παραμένουν ίδια). Τυχόν ήδη αποθηκευμένη προσωπική τιμή διαλείμματος διατηρείται. Ενημερώθηκε επίσης η PWA cache για να διανεμηθεί η αλλαγή.

## Σημειώσεις προηγούμενης έκδοσης 307


Η έκδοση 307 είναι συντήρηση της σταθερής 306. Ενοποιεί τις παραμέτρους ανανέωσης του service worker, προσθέτει ελέγχους παλινδρόμησης και διορθώνει την παρωχημένη τεκμηρίωση. **Δεν αλλάζει εμφάνιση, ασκήσεις, σετ, αποθήκευση ή λειτουργίες.**

Οι παρακάτω σημειώσεις περιγράφουν τις προηγούμενες αλλαγές που διατηρούνται.

## Τι άλλαξε

- Εβδομαδιαία πρόοδος: μηδενισμός κάθε **Δευτέρα 00:00, ώρα Ελλάδας (Europe/Athens)**, στον πρώτο έλεγχο μετά την αλλαγή εβδομάδας.
- Τα ιστορικά δεδομένα και το πρόγραμμα παραμένουν αποθηκευμένα. Η τελευταία εβδομάδα κρατά επιπλέον στιγμιότυπο στο `pegasus_weekly_history_archive_v1`.
- Σάββατο: η λίστα ξεκινά από την κορυφή και οι **Leg Extensions, Reverse Crunch, Plank** παραμένουν στον σταθερό σχεδιασμό (3 / 3 / 2 σετ).
- Το προεπιλεγμένο mode Σαββάτου είναι «Βάρη» αν δεν έχει αποθηκευτεί προτίμηση. Όλες οι επιλογές Ποδήλατο / Ποδ. + βάρη / Βάρη παραμένουν διαθέσιμες.
- Ανανεώθηκαν οι εκδόσεις cache/service worker για να φορτωθούν οι αλλαγές.

## Δεδομένα και βίντεο

- Το PEGASUS είναι **local-only**. Το `cloudSync.js` διατηρείται ως παλιό συμβατό αρχείο αλλά **δεν φορτώνεται**, επομένως δεν υπάρχει αυτόματος συγχρονισμός μεταξύ συσκευών.
- Για μεταφορά δεδομένων χρησιμοποίησε **Αποθήκευση αρχείου / Φόρτωση αρχείου** ή πλήρες τοπικό αντίγραφο / ασφαλή επαναφορά.
- Ο φάκελος `videos/` **δεν περιλαμβάνεται** στο πακέτο που δόθηκε για επεξεργασία. Κράτησέ τον ανέπαφο στο GitHub/στη συσκευή.
- Πριν από την ενημέρωση, πάρε τοπικό αντίγραφο των δεδομένων σου. Το ZIP του πηγαίου κώδικα **δεν** περιλαμβάνει τα προσωπικά δεδομένα που αποθηκεύει ο browser.

## Ενημέρωση

Αν ανεβάζεις μόνο τις αλλαγές, διατήρησε την ίδια δομή φακέλων. Αν χρησιμοποιείς το πλήρες ZIP, μην διαγράψεις τον υπάρχοντα φάκελο βίντεο ή άλλα αρχεία που δεν περιλαμβάνονται στην αποστολή.
