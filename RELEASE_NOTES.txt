PEGASUS 297

- Cloud sync: added quiet backoff mode for temporary JSONBin/fetch failures.
- Pull/push no longer spam the Console with repeated red errors when the cloud or network is temporarily unavailable.
- Pending local changes remain queued and are retried after the backoff window.
- Approved-device restore, focus/visibility sync, deferred sync and push now respect the same backoff guard.
- Weather fetch failures now degrade quietly with a throttled warning instead of repeated red errors.
- Workout 40-minute guard, mobile timer settings, parking timestamps and permanent video cache fixes from previous versions are preserved.
- Desktop/mobile data is not reset; this is a sync-noise and retry-safety patch.
