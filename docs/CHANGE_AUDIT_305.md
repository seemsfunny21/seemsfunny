# PEGASUS 305 — Προσεκτική συντήρηση & ονόματα ασκήσεων

## Στοχευμένες αλλαγές

- Όλες οι εγγεγραμμένες ασκήσεις εμφανίζονται στα ελληνικά για GR και αγγλικά για EN.
- Το εσωτερικό αναγνωριστικό της άσκησης παραμένει σταθερό (English canonical): ονόματα βίντεο, βάρη, σειρά drag-and-drop, πρόοδος και εξαγωγές δεν μεταφράζονται στην αποθήκευση.
- Η επιφάνεια εμφάνισης των ασκήσεων στην αριστερή λίστα σημειώνεται με `data-i18n-kind=exercise` και `data-i18n-source` ώστε να ενημερώνεται κατά την εναλλαγή γλώσσας.
- Ο έλεγχος ολοκληρωμένων εβδομαδιαίων στόχων, οι αναφορές και η προεπισκόπηση προόδου διαβάζουν πρώτα το canonical `data-name`.
- Τα ονόματα ασκήσεων στους στόχους και στην καταγραφή βαρών κινητού εμφανίζονται μεταφρασμένα αλλά αποθηκεύονται ως canonical.
- Πρόθεμα προεπισκόπησης επόμενης άσκησης `Επόμενη:` / `Next:`.
- Cache service worker `305` και query στο τροποποιημένο mobile asset.

## Αμετάβλητα

- CSS, HTML δομή καρτών, timer, σετ, πρόγραμμα, βίντεο και αρχείο δεδομένων.
- Διορθώσεις PEGASUS 304: reset Δευτέρα 00:00 (Europe/Athens), αρχική εμφάνιση 3 ασκήσεων Σαββάτου.

## Περιορισμοί

- Στατικός έλεγχος και στοχευμένες δοκιμές δεν ισοδυναμούν με εγγύηση ότι η μεγάλη εφαρμογή δεν έχει κανένα άλλο σφάλμα.
- Η εμφάνιση ελέγχθηκε για βασικές αλλαγές στον DOM/κώδικα, όχι σε κάθε συσκευή/ανάλυση.
- Η έκδοση 304 είναι local-only· δεν εισάγεται ξανά cloud synchronization.
