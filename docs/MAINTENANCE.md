# PEGASUS 307 — Οδηγός συντήρησης

## Κατάσταση

- **Σταθερό baseline:** PEGASUS 306, ταυτοποιημένο με τα 97 αρχεία του RAR που παρέδωσε ο χρήστης.
- **PEGASUS 307:** μόνο συντήρηση. Δεν τροποποιούνται CSS, αριθμοί σετ, ασκήσεις, βίντεο, workouts, progress logic, αποθήκευση/επαναφορά ή η εμφάνιση των λιστών.
- **Τοπική έκδοση (local-only):** δεν ενεργοποιείται ο παλιός `cloudSync.js`. Desktop και κινητό δεν συγχρονίζονται αυτόματα.

## Εκκίνηση και βασικά σημεία

- Desktop: `index.html`, scripts `manifest.js` → `app.js` και συμπληρωματικά modules.
- Mobile: `mobile/mobile.html`, `mobile/*.js`, `mobile/style.css`.
- Service worker: `sw.js`, namespace μόνιμης cache `pegasus-permanent-local-v307`.
- Τρεις εγγραφές registration SW: `index.html`, `app.js`, `mobile/mobile.html` έχουν το **ίδιο** URL version token `v=3.36.307`.
- Το `sw.js` κρατά παλιές μόνιμες caches για μεταφορά offline media. **Μην διαγράφετε** παλιές `pegasus-permanent-local-*` caches στο update.
- Ο φάκελος `videos/` δεν περιλαμβάνεται στο παραδοτέο ZIP· πρέπει να παραμείνει στο υπάρχον repository.

## Κανόνες συμπεριφοράς που δεν αλλάζουμε

1. **Εβδομαδιαία πρόοδος:** κάθε Δευτέρα 00:00 Europe/Athens. Το `manifest.js` παρέχει `PegasusWeekClock` και τον shared rollover. Να παραμένουν ακέραια τα προηγούμενα workouts και το `pegasus_weekly_history_archive_v1`.
2. **Σάββατο:** ακριβώς `Leg Extensions` (3 σετ), `Reverse Crunch` (3), `Plank` (2). Ο καθυστερημένος optimizer στο `dynamic.js` δεν πρέπει να κρύβει το πρώτο, ακόμη και μετά από δεύτερη εκτέλεση.
3. **Μετάφραση:** οι 24 ασκήσεις έχουν GR/EN ονομασία εμφάνισης. Η ταυτοποίηση σε ιστορικό, βίντεο και προγραμματισμό γίνεται με το canonical αγγλικό όνομα (`data-name`), όχι το μεταφρασμένο κείμενο.
4. **Σαββατοκύριακο:** παραμένουν οι επιλογές `Ποδήλατο`, `Ποδ. + βάρη`, `Βάρη`, με αποθήκευση επιλογής.
5. **Offline βίντεο:** διατήρηση παλιών permanent caches για μετάβαση σε νέα έκδοση και αποφυγή επαναφόρτωσης μεγάλων αρχείων.
6. **Mobile:** διατηρούνται τα modules, τα τοπικά backups και η φόρτωση χωρίς PIN/cloud lock.

## Έλεγχοι πριν από κάθε νέα έκδοση

Με εγκατεστημένο Node.js >= 18 στο root του repository:

```bash
node tests/regression.test.js
```

Το script εκτελεί εννέα ομάδες δοκιμών για: όρια εβδομάδας και DST, μηδενισμό χωρίς απώλεια δεδομένων, upgrade εντός εβδομάδας, πρόγραμμα Σαββάτου, delayed optimizer, τις 24 μεταφράσεις, συμφωνία εκδόσεων SW, ύπαρξη στατικών assets και σύνταξη `.js`.

Απαιτούνται επιπλέον **χειροκίνητες δοκιμές στο κανονικό browser** πριν θεωρηθεί η νέα έκδοση πλήρως πιστοποιημένη: desktop και mobile startup, Start/Pause/Next/Rest, timers, αλλαγή μέρας, αλλαγή γλώσσας, επιλογές σαββατοκύριακου, αποθήκευση βαρών, εισαγωγή/εξαγωγή backup, εβδομαδιαία πρόοδος, video playback και offline/reopen. Οι αυτόματες δοκιμές δεν καλύπτουν πλήρως αυτές τις ροές.

## Ασφάλεια δεδομένων και εγκατάσταση

- Κρατήστε την 306 ως δυνατότητα επαναφοράς και **εξάγετε πραγματικό backup μέσα από την εφαρμογή** πριν το update. Το ZIP κώδικα δεν περιέχει browser `localStorage` ή `IndexedDB`.
- Για ενημέρωση, αντικαταστήστε μόνο τα αρχεία του ZIP αλλαγών· μην σβήνετε τα παλιά media, δεδομένα, ή άγνωστα runtime αρχεία.
- Αν η εμφάνιση/συμπεριφορά αλλάξει απροσδόκητα, ελέγξτε ενεργό service worker και cache πριν επιχειρήσετε χειροκίνητο reset. **Μην διαγράφετε site data** ως βήμα troubleshooting χωρίς backup.

## Αναβολή ριψοκίνδυνων απλοποιήσεων

Δεν ενοποιούνται αυτή τη στιγμή οι επάλληλοι CSS κανόνες, δεν διαγράφονται legacy αρχεία (`cloudSync.js` κ.λπ.) και δεν συγχωνεύονται διαφορετικά runtime modules. Τέτοιες αλλαγές απαιτούν πλήρη οπτική και λειτουργική δοκιμή σε πολλές συσκευές. Οι παλαιότερες οδηγίες στα `CHANGE_AUDIT_30x.md` είναι ιστορικά αρχεία των προηγούμενων εκδόσεων.
